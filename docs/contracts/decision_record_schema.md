# 결정 기록(Decision Record) 공통 스키마

**Epic 하나(전체 조율)와 역할(R1~R4) 하나당 결정 기록 파일 하나.** `docs/review/decisions/00-overall.md`는 Epic([#1](https://github.com/hoho-ajou/hoho_ajou/issues/1))의, `docs/review/decisions/r1~r4-*.md`는 각 역할([`docs/governance/OWNERSHIP.md`](../governance/OWNERSHIP.md))의 결정 기록입니다. 이슈/논의 전부를 담지 않고, **확정된 최종 결정과 그 근거만** 남깁니다.

## 언제 채우나

담당자가 설계를 진행하며 실제로 선택지가 갈렸던 지점만 기록하면 되고, 결정할 게 없었다면 빈 상태로 둡니다.

## 필수 섹션 (순서 고정)

```markdown
# 결정 기록 — <Epic 제목 또는 역할명>

## 담당 역할 (또는 상위 이슈)
(Epic이면 GitHub Issue 링크, 역할이면 R1~R4 중 어느 것인지 + OWNERSHIP.md 링크)

## 하위 이슈 분할
(실행 단위로 어떻게 나눴는지. 하위 이슈 번호로 참조)
- #<번호> — <한 줄 설명>

## 결정 사항

### 결정 1 — <제목>
**결정하려 했던 것**: (선택지가 갈렸던 지점, 있었던 옵션)
**근거**: (왜 이걸 골랐는지)
**최종 결정**: (실제로 어떻게 하기로 했는지, 관련 스키마 필드가 있으면 명시)

### 결정 2 — <제목>
...
```

## 필드 규칙

| 필드 | 규칙 |
|---|---|
| 담당 역할 | Epic 결정 기록은 GitHub Issue #1 링크, 역할 결정 기록은 R1~R4 표기 + OWNERSHIP.md 링크 |
| 하위 이슈 분할 | 담당자가 하위 이슈를 아직 안 만들었으면 "(하위 이슈 생성 전)"이라고 명시. 다 만든 뒤에는 실제 번호로 채움 |
| 결정 사항 | 이슈 안에서 오간 논의 전부가 아니라 **최종 결론이 난 것만**. 다른 역할에 영향을 주는 결정은 근거에 어느 역할이 영향받는지 명시 |
| 결정할 게 없는 경우 | "## 결정 사항" 아래에 "(별도로 결정할 사항이 없었음)"이라고 명시 |

## 다른 문서와의 관계

- 실제 스키마 값은 여기서 재정의하지 않고 `schemas/*.schema.json`을 가리킵니다.

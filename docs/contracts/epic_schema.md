# 상위 이슈(Epic) 공통 스키마

`docs/epics/*.md`는 전부 이 스키마를 따릅니다. 전체 흐름(필드 구성)은 공통으로 고정하되, 각 필드 안의 내용은 담당자가 자유롭게 씁니다 — 형식을 통일하는 게 목적이지, 내용까지 획일화하는 게 목적이 아닙니다.

## 필수 섹션 (순서 고정)

```markdown
# [Epic] <모듈명 또는 결정 대상> <동사형 제목>

## 목표
(이 이슈가 끝나면 무엇이 가능해지는지. 자유 서술)

## 범위
(이 이슈가 어디까지 담당하는지 — 포함/제외를 담당자가 편한 방식으로 서술)

## 완료조건
(참/거짓을 판정할 수 있는 조건. 개수·형식 자유)

## 공통계약
(이 이슈가 지켜야 하는 `schemas/*.schema.json`, `docs/contracts/*.md` 등을 명시. 여기서 필드를 새로 정의하지 않고 해당 파일을 고침 — 공통 계약 파일이 단일 진실 공급원(SSOT))

## 담당 문서
(이 이슈가 주로 채우는 문서 경로 — 보통 `docs/design/0X-*.md`)

## 하위 이슈
(담당자가 프로젝트 진행 상황에 맞춰 직접 세분화하여 생성 예정 — 여기서는 만들지 않습니다)
```

## 고정인 것 / 자유인 것

| | 고정 | 자유 |
|---|---|---|
| 섹션 순서·이름 | ✅ 위 6개 그대로 | |
| 각 섹션 내용의 서술 방식 | | ✅ 표/불릿/산문 등 담당자 재량 |
| "공통계약"에서 참조하는 스키마 파일 자체 | ✅ 실제 존재하는 파일만 인용 | |
| "하위 이슈" 섹션 문구 | ✅ 임의로 바꾸지 않음 | |

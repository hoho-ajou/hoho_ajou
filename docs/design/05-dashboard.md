# Dashboard 설계 (05-dashboard.md)

> 담당: 전선재 (R4) · 상위 이슈 #12
> 상태: 설계 초안 (작성 중)

## 1. 개요
- 목적: Attack Path Engine의 출력(그래프 + 공격 경로)을 웹에서 인터랙티브하게 시각화한다.
- 범위(포함): 화면 구성, 시각화 방식, 필터링, 백엔드 API 형태
- 범위(제외): 실제 코드 구현, 사용자 인증, 실시간 스트리밍

## 2. 화면 구성
| 뷰 | 내용 |
|---|---|
| 전체 그래프 | 패키지·에이전트·도구·권한 노드와 관계를 그래프로 표시 |
| 공격 경로 하이라이트 | 선택한 공격 경로를 강조 표시 |
| 위험 자산 목록 | 위험도 높은 노드·경로를 목록으로 정렬 |
| 상세 패널 | 경로 클릭 시 단계·침해 시나리오 표시 |

## 3. 시각화 방식
- 라이브러리 후보: Cytoscape.js(그래프 특화) vs D3.js — 선정 근거 문서화 예정
- 노드 표현: 타입별 모양·색 구분, 위험도에 따른 색상 스케일
- 엣지 표현: 관계 타입(depends_on/loads/grants 등) 구분

## 4. 필터링
- 위험도 임계값 이상만 보기
- 노드 타입별 필터 (패키지/도구/권한)
- 특정 공격 경로만 보기

## 5. 백엔드 API (형태 설계)
| 엔드포인트 | 설명 |
|---|---|
| `GET /api/graph` | 전체 그래프(노드·엣지) 반환 |
| `GET /api/attack-paths?min_risk=` | 공격 경로 목록(위험도 순) |
| `GET /api/attack-paths/{id}` | 특정 경로 상세(단계·시나리오) |

- 입력: Attack Path Engine 출력(JSON)
- 상세 데이터 구조는 04-attack-path.md 및 R4-1 입력 계약 참조

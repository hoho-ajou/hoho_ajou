# [Epic] Dashboard 설계 문서 완성

## 목표

Attack Path Engine이 만든 `attack_graph.json`을 지도교수·쿤텍 자문단이 웹 브라우저에서 바로 열어 "어떤 자산이 왜 위험하고, 어떤 경로로 실제 피해까지 이어지는지"를 직관적으로 판단할 수 있는 인터랙티브 대시보드의 **설계를 AI 구현 가능한 수준까지** 완성한다. 실제 프론트엔드/백엔드 코드 작성은 범위 밖이다.

## 범위

`docs/design/05-dashboard.md`를 심화 작성한다:
- Cytoscape.js 그래프 뷰 설계(스타일링, 레이아웃 전환)
- risk_score 필터링·검색 동작 규칙
- 리스트 뷰 ↔ 그래프 하이라이트 연동 방식
- 상세 정보 패널 필드 목록
- FastAPI 백엔드 엔드포인트 설계
- PNG 내보내기 방식

**범위 밖**: 실시간 스트리밍, 다중 사용자 인증, 그래프 데이터 재계산, **실제 프론트엔드/백엔드 코드 구현**

## 완료조건

- [ ] 그래프 뷰·필터링·리스트 연동·상세 패널의 동작 규칙이 구체적으로(입력 이벤트 → 화면 변화) 서술되어 있다
- [ ] 샘플 JSON 예시와 화면 렌더링 매핑이 있다
- [ ] FastAPI 엔드포인트 목록(경로, 메서드, 요청/응답 형식)이 명시되어 있다
- [ ] 최소 2개 엣지케이스가 표로 정리되어 있다
- [ ] 시연 시나리오("노드 클릭 → 상세정보 → 경로 하이라이트")가 화면 흐름으로 문서화되어 있다

# AI Software Supply Chain Threats Escalate in 2026

원문: https://www.esecurityplanet.com/threats/ai-software-supply-chain-threats-escalate-in-2026/
(JFrog "Software Supply Chain Security State of the Union 2026" 리포트 인용)

## Key Findings

**Malicious Package Activity:**
- Malicious npm packages surged 451% in 2025, reaching over 171,000 unique packages
- 11.7 million new packages entered enterprise supply chains in 2025 (67% increase year-over-year)
- Multiple campaigns resulted in over 2 million compromised downloads

**AI Model Threats:**
- Researchers identified nearly 500 malicious AI models in public registries
- 53% of organizations pull AI models directly from public registries like Hugging Face
- Malicious models contain payloads for credential theft, code execution, and system compromise

**Vulnerability Landscape:**
- Over 48,000 new CVEs disclosed in 2025 (20% increase)
- 96% of "Critical" vulnerabilities were downgraded after contextual analysis
- Only 12% considered highly exploitable in enterprise environments

**Governance Gaps:**
- 18% of organizations lack active governance policies for developer AI tools
- 48% require a week or more to generate compliance audit evidence

## Recommendations
- Implement automated scanning across repositories and CI/CD pipelines
- Extend governance to cover AI models and developer tools
- Enforce software provenance tracking and SBOM generation
- Apply least privilege access and MFA controls
- Conduct secure code reviews for AI-generated code
- Test incident response plans regularly

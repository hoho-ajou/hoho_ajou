# How AI Agents Expand the Software Supply Chain Attack Surface

원문: https://socket.dev/blog/ai-agents-supply-chain-attack-surface
(Socket, Sarah Gooding, 2026-08-16)

## Article Overview
This Socket blog post documents a presentation by Feross Aboukhadijeh, Socket's founder and CEO, delivered at AI Council 2026. The article examines how AI coding agents are reshaping software supply chain security threats.

## Key Points from the Talk
**Three Main Developments Highlighted:**
1. AI agents increasingly select, install, and execute third-party code
2. Traditional security infrastructure relies on human trust decisions
3. This infrastructure struggles to keep pace with machine-speed development

**Attack Methods Discussed:**
The presentation references major 2026 supply chain incidents involving Axios, TanStack, and Trivy. Attack vectors include:
- Compromised maintainers
- Malicious transitive dependencies
- Prompt injection attacks
- Trusted development tools manipulation

**Additional Risk Areas:**
The talk covers vulnerabilities across MCP servers, agent skills, and IDE extensions, plus pressures AI-assisted vulnerability discovery creates for security teams.

## Perspective Offered
Aboukhadijeh provides "a more optimistic view" of how these same AI capabilities assist defenders in analyzing open source code, prioritizing vulnerabilities, and strengthening software security overall.
